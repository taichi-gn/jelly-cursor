# JellyCursor

動かすと伸びて、止めると揺れて戻る macOS のマウスカーソル。メニューバーに常駐します。

![矢印と I 字の動き](docs/images/motion.gif)

<sub>左が矢印、右が文字の上の I 字。灰色の輪は、ボタンを押している間</sub>

- **矢印**: 通った道に沿って伸び、進む向きを指す。左右に振ると、端で縮んですばやく向きを変える。止めると振り子のように揺れて、左上向きに戻る
- **文字の上の I 字**: 横に動かすと太く、縦に動かすと長くなり、斜めに動かすとその向きに傾く
- **リンクの上の指**: 進む向きを指差して伸び、止めると上向きに戻る
- **クリック**: 押すと少しつぶれ、離すと弾んで戻る（クリックする位置はずれない）

ほかのカーソル（ウインドウの大きさを変えるときの矢印など）やシステムのダイアログの上、動画や文字入力でカーソルが隠れている間は、macOS のカーソルのままです。

## 入れ方

macOS 14 以降で動きます。作るには Swift 6 が要ります（Xcode は無くてもよく、`xcode-select --install` で入る Command Line Tools で作れます）。

```sh
git clone https://github.com/taichi-gn/jelly-cursor.git
cd jelly-cursor
make install
```

`~/Applications` に入り、そのまま起動します。新しくするときは、`git pull` してからもう一度 `make install` します。

## 使い方

メニューバーのアイコンから、オン・オフ（「有効」）と動きの強さ（控えめ・標準・大きめ）を選べます。オフにすると、macOS のカーソルが見えるところまで確かに戻します。

<img src="docs/images/menu.png" width="216" alt="メニュー">

設定画面（メニューの「設定…」か ⌘,）では、次のことを決められます。

- **一般**: ログイン時に起動、メニューバーのアイコンを出すか、オン・オフのショートカット
- **動き**: 動きの強さ（「伸び」と「弾み」）、クリックで弾むか（プレビューで確かめられます）
- **カーソル**: 矢印・I 字・指を、種類ごとにオン・オフ
- **自動一時停止**: 「視差効果を減らす」がオンのとき、低電力モードのとき、フルスクリーンのアプリを使っているとき（どれも最初はオフ）と、指定したアプリを使っているときに一時停止
- **情報**: バージョンと今の状態、困ったときの案内、診断情報のコピー

<img src="docs/images/settings-motion.png" width="420" alt="設定画面の動きのタブ">

- 画面のロック中やスリープ中などは、いつも一時停止して、macOS のカーソルに戻します
- メニューバーのアイコンを隠したときは、JellyCursor をもう一度開くと設定画面が表示されます

## 困ったとき

- **カーソルが見えなくなった**: ショートカットかメニューの「有効」でオフにします。ターミナルで `killall JellyCursor` を実行すると、macOS のカーソルに戻してから終了します
- **起動するとおかしくなる**: Shift キーを押しながら開くと、オフの状態（セーフモード）で起動します。メニューか設定で有効にすると動きます
- **動きがおかしい**: 設定の「情報」タブの「診断情報をコピー」で、状況をまとめてコピーできます。それを添えて知らせてください
- **設定を消したい**: JellyCursor を終了してから、ターミナルで `defaults delete local.jellycursor` を実行します

## 仕組み

画面の上に透明な窓を重ね、macOS のカーソルを隠して、変形させた形を描いています。前面にいないアプリからカーソルを隠すには非公開 API（`SetsCursorInBackground`）が要ります。それが使えない macOS では、矢印だけを macOS のカーソルに重ねて描き、メニューで知らせます。

## 開発

```sh
make run
make test
```

`make run` は作ってその場で開き、`make test` は試験を回します。動きの計算（`JellyCursorCore`）は AppKit を使わないので、Linux でも試験を回せます。上の GIF は `docs/motion-gif/make.sh` で作り直せます。
